# マハロカーズ GS専門LP

## ファイル構成
- `index.html` … LP本体
- `cars.json` … 在庫データ（これだけ編集すれば在庫更新できます）
- `images/` … 車両写真（アップロードいただいたスクリーンショットから仮で切り出したものです）

## 公開前に差し替えが必要な箇所

1. **Google広告のコンバージョンID**
   `index.html` 内の `GTM-XXXXXXX`（2箇所）を、実際のGoogleタグマネージャーのコンテナIDに差し替えてください。

2. **古物商許可番号**
   店舗情報セクションの「※許可番号をご記入ください」の部分に実際の番号を入れてください。

3. **車両写真**
   `images/car1.jpg`〜`car6.jpg` は、送っていただいたスクリーンショットから仮に切り出した画像です。
   実際の掲載用には、カーセンサー／グーネットに登録している高画質の写真に差し替えることを推奨します
   （ファイル名を同じ `car1.jpg` などにして上書きすればOK）。

4. **お問い合わせフォームの送信先**
   現在 `formsubmit.co`（無料・登録不要のフォーム転送サービス）を使う設定にしています。
   初回だけ、公開後に一度テスト送信すると `info@mahalocars.jp` 宛に確認メールが届くので、
   メール内のリンクをクリックすると以降は自動で転送されるようになります。

## 在庫を更新するとき

`cars.json` を開いて、該当車両の情報を書き換える・追加する・削除するだけです。
HTML本体は一切触る必要はありません。

売約済みにする場合は削除せず `"status": "sold"` に変更すると、LP上には表示されなくなります
（記録として残しておきたい場合向け）。

## GitHub Pagesでの公開手順（概要）

1. GitHubでリポジトリを新規作成（例：`mahalocars-gs-lp`）
2. このフォルダの中身（`index.html` / `cars.json` / `images/`）をすべてアップロード
3. リポジトリの Settings → Pages で公開を有効化
4. 発行されたURL（例：`https://ユーザー名.github.io/mahalocars-gs-lp/`）を
   Google広告の「最終ページURL」に設定

独自ドメイン（`mahalocars-gs.com`など）を使いたい場合は、
ドメイン取得後にGitHub Pagesのカスタムドメイン設定から紐付けできます。
